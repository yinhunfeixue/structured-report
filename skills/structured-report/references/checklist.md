# 交付前门禁清单

A~D 四组共 16 条，对应 `SKILL.md` 的 16 条硬约束，全过才能交。末尾两问是收尾检查，不计入门禁条数。

没有第二级清单 —— 不遵守也不会出事实性错误的条目，不放在门禁里。

逐条核对，不要整体扫一眼就算过。前两组最容易漏，也最贵。

## A. 口径

- [ ] **1** 数据源、时间边界、主体标识、纳入排除、基准来源五项都已确认，没有靠猜
- [ ] **2** 口径写在文档头部，读者照着能复现每个数字
- [ ] **3** 实际范围与用户说法不一致时按实际写，并在头部说明了差异
- [ ] **4** 每一行对比指标的两期跨度相同；不同的已注明
- [ ] **5** 没有估算出来的数字；缺口用 `【待补：xxx】` 标出

## B. 归属

- [ ] **6** 含他人产出的成果注明了产出者与分工边界
- [ ] **7** 每个转述来的数字注明了出处；逐个问过「这个数我自己算过吗」
- [ ] **8** 未经二次验证的结论前缀「判断：」或「推测：」
- [ ] **9** 指标表里的增量若含他人产出，表下已注明分工

## C. 范围

- [ ] **10** 每一节都回答用户提的那个问题；讲其他范围的节已删
- [ ] **11** 范围内的风险与失败都报了，没因为「用户只问进展」而隐去
- [ ] **12** 没有自行添加下期计划、上期回顾、附录这类用户未要求的章节

## D. 表达

- [ ] **13** 第一句是结论，不是背景，不是「本期做了以下工作」
- [ ] **14** 事实与观点分开成句，观点已标注
- [ ] **15** 内容层是列表项，每项为「粗体短语 + 破折号 + 句子」，两者同一行
- [ ] **16** 每个列表项都携带数据、根因、状态变化、口径定义四类之一

## 两问收尾

- [ ] **So What** —— 每句话能答出「所以呢」，答不出的已删
- [ ] **Why** —— 每个结论能答出「凭什么」，答不出的已补证据或降级为判断
